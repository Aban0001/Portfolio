Introuge

Introuge

Beskrivelse af tema

Introugen var det første tema på Multimediedesignuddannelsen og fungerede som en introduktion til både studiet og arbejdsformen. I dette forløb blev vi introduceret til grundlæggende begreber inden for idéudvikling, research, visuel kommunikation og digital produktion. Temaet havde fokus på at lære hinanden, uddannelsen og de værktøjer, vi skal arbejde med gennem studiet, at kende.

Proces, løsning & resultater

I introugen arbejdede vi med research og idéudvikling til en titel-intro, som skulle formidle et budskab visuelt gennem video. Processen bestod af idé-generering, skitsering og planlægning, efterfulgt af optagelse og redigering af video. Vi arbejdede med simple videoredigeringsværktøjer og lærte grundlæggende principper for klipning, timing og visuel fortælling.

Derudover blev vi introduceret til vigtige studie- og samarbejdsværktøjer som ItsLearning, Figma, GitHub og præsentationsformer. Forløbet gav mig en forståelse for, hvordan man arbejder projektorienteret på uddannelsen, og hvordan samarbejde, struktur og planlægning spiller en central rolle i multimediedesignprocesser.

Introugen gav et godt fundament for resten af 1. semester og gjorde mig mere tryg i både det faglige og sociale aspekt af studiet.

Grundlæggende Web

Grundlæggende Web

Beskrivelse af tema

I temaet Grundlæggende Web arbejdede jeg med de grundlæggende teknologier og principper bag opbygningen af websites. Fokus var på HTML og CSS, herunder korrekt mappestruktur, semantisk markup, styling, layout og responsivt design. Temaet gav en forståelse for, hvordan struktur, indhold og præsentation hænger sammen i webudvikling.

Proces, løsning & resultater

Arbejdet startede med introduktion til HTML og CSS samt opsætning af korrekt fil- og mappestruktur. Jeg arbejdede med HTML-elementer, semantiske tags som header, main, section og footer, samt korrekt brug af links, billeder og lister.

Herefter blev der arbejdet med CSS til styling, herunder farver, typografi, margin, padding og layout. Jeg lærte at bruge både Flexbox og CSS Grid samt media queries til at gøre siderne responsive. Undervejs blev koden valideret med W3-validator for at sikre korrekt syntaks.

Resultatet var et mobilsite og et website, som er opbygget med semantisk HTML og stylet med CSS. Siderne har en tydelig struktur, navigation og visuel sammenhæng og fungerer på både mobil og desktop. Projekterne blev uploadet til GitHub og publiceret via GitHub Pages, så de kunne tilgås online.

Gennem temaet har jeg opnået en grundlæggende forståelse for, hvordan websites bygges fra bunden. Jeg har lært at strukturere HTML korrekt, arbejde systematisk med CSS og skabe responsive layouts. Derudover har jeg fået erfaring med versionsstyring via GitHub og vigtigheden af validering, struktur og genbrugelig kode i webudvikling.

Grundlæggende UI/UX

Grundlæggende UI/UX

Beskrivelse af tema

I dette tema arbejdede jeg med grundlæggende UI/UX-principper og brugercentreret design. Fokus var på at forstå brugernes behov og adfærd gennem research og tests samt at omsætte denne viden til funktionelle og brugervenlige digitale løsninger. Temaet introducerede metoder inden for research, idéudvikling, wireframing og prototyping samt grundlæggende designprincipper som hierarki, kontrast, konsistens og læsbarhed.

Proces, løsning & resultater

Arbejdet startede med research, hvor jeg blandt andet arbejdede med brugerundersøgelser, user types og problemformulering. På baggrund af researchen udviklede jeg idéer og skitser, som blev videreudviklet til lo-fi wireframes og interaktive prototyper i Figma.

Jeg anvendte forskellige testmetoder såsom tænke-højt-test, 5-second test og Likert-tests for at evaluere brugervenlighed og forståelse. Feedback fra tests blev brugt til at iterere og forbedre designet.

Resultatet var en digital prototype med fokus på klar struktur, tydelig navigation og en god brugeroplevelse. Temaet gav mig en grundlæggende forståelse for, hvordan UI-design og UX-metoder hænger sammen, og hvordan designvalg kan begrundes ud fra brugerindsigter og testresultater.

Temaet har givet mig en solid forståelse for, hvordan research og test kan bruges aktivt i designprocessen for at skabe mere brugervenlige løsninger.

Grundlæggende Brugergrænsefladeudvikling

Grundlæggende Brugergrænsefladeudvikling

Beskrivelse af tema

I temaet Grundlæggende Brugergrænsefladeudvikling arbejdede vi med at omsætte design og idéer til fungerende, interaktive brugergrænseflader. Fokus var på, hvordan HTML, CSS og JavaScript kan bruges til at skabe dynamiske og brugervenlige løsninger.

Proces, løsning & resultater

Vi arbejdede med JavaScript til at tilføje interaktion, herunder funktioner som popovers, accordions, toggles og formularer. Derudover lærte vi at arbejde med SVG, infografik og grafiske elementer samt grundlæggende tilgængelighed og forms. Temaet samlede både design og kode og resulterede i en mere interaktiv og funktionel brugergrænseflade, hvor brugeren aktivt kan interagere med indholdet.

Temaet gav mig en bedre forståelse for samspillet mellem design og kode, og hvordan selv små JavaScript-løsninger kan bruges målrettet til at forbedre brugeroplevelsen.

Grundlæggende Indhold

Grundlæggende Indhold

Beskrivelse af tema

I dette tema arbejdede vi med indholdsproduktion til digitale løsninger med fokus på tekst, billeder og samarbejde i grupper. Temaet handlede om, hvordan indhold planlægges, produceres og struktureres, så det understøtter både brugerens behov og formålet med sitet.

Proces, løsning & resultater

Vi arbejdede med research, idéudvikling og wireframes som grundlag for indholdsproduktion og udviklede en sandkassesite og senere en virksomhedswebsite. Derudover arbejdede vi med SCRUM, samarbejdskontrakter og procesdokumentation for at strukturere gruppearbejdet.

Jeg lærte at producere og tilpasse indhold i form af tekst og billeder, arbejde med visuel branding samt anvende værktøjer som Photoshop, Illustrator og Adobe Firefly. Temaet gav mig en bedre forståelse for, hvordan indhold, visuel stil og struktur spiller sammen, og hvordan godt indhold bidrager til en klar og sammenhængende brugeroplevelse.

Temaet gav mig en større forståelse for indholdsproduktion og samarbejde i digitale projekter samt vigtigheden af, at indhold understøtter både design og funktion.
